# 04 — Intent-Aware Search

**Status:** Proposal — extend Plan 05 rather than create a competing search implementation.

## Problem
Search is less useful when users must know exact titles or manually switch between tracks, albums, artists, playlists, and other supported media types.

## Brief solution
Improve unified result grouping, typo tolerance, recent searches, useful filters, and empty/ambiguous-result guidance. Respect each provider's actual search capabilities and show source attribution.

## Expected outcome
Users find the intended item with fewer queries and understand why a result is or is not available.

**Acceptance signal:** a representative query set measures successful discovery, zero-result rate, and time-to-open across supported providers.
