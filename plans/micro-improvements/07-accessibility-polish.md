# 07 — Accessibility Polish

**Status:** Proposal — consolidate with Plans 02, 073, 074, and 084 before implementation.

## Problem
Small interaction and navigation barriers can make everyday listening harder for users relying on screen readers, larger text, keyboard navigation, or reduced motion.

## Brief solution
Run a cross-platform accessibility audit. Fix semantics and focus order, text scaling and clipping, contrast, touch-target sizing, keyboard operation, and reduced-motion behaviour. Preserve essential feedback when decorative motion is disabled.

## Expected outcome
Core browse, search, library, settings, and playback flows remain understandable and operable with accessibility features enabled.

**Acceptance signal:** automated accessibility checks plus manual screen-reader, keyboard, large-text, and reduced-motion walkthroughs pass on supported platforms.
