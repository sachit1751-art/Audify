# 05 — Personalized Home

**Status:** Proposal — reconcile with Plan 090 and existing home-layout settings.

## Problem
A fixed home screen can bury the sections a user actually uses and give too much space to irrelevant content.

## Brief solution
Allow supported home sections to be reordered, hidden, or pinned, with sensible defaults and a simple reset option. Persist preferences safely and keep the layout usable on phone, tablet, desktop, and TV.

## Expected outcome
The home screen prioritizes relevant content without becoming complicated to configure.

**Acceptance signal:** preferences persist across restarts and layouts remain accessible at supported window sizes.
