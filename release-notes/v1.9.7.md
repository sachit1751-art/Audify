# Audify 1.9.7

## Settings recovery

- Prevents first-install defaults from being written over any non-empty preferences store.
- Recovers legacy settings that 1.9.5 may have replaced with first-install defaults, but only when the current values still match the known seeded defaults.
- Preserves values changed after the affected update and performs the recovery check only once.
- Adds regression coverage for safe restoration.
