# Audify 1.9.5

## Scrolling and rendering performance

- Removed per-card spring, alpha and scale entrance animations from actively scrolling horizontal shelves. Shelf cards now enter without competing animation work while the row is flinging.
- Retained bounded nested-shelf prefetching and snap-to-card horizontal scrolling.
- Progressive Blur now defaults to **off** on fresh installs, including the first-run preference seed. An explicitly saved user choice remains unchanged during upgrades.

## Version and build

- Phone, Wear OS and Android TV production artifacts use version **1.9.5 (44)**.
- Production APKs are built for universal, ARM64, ARMv7 and x86_64 variants; all 12 passed APK signature verification and report version 1.9.5 (44) with the same signing certificate.
- Shared UI JVM tests and production-debug unit tests passed: 1,308 tests, zero failures, zero errors, one skipped.
- Frame-time improvement still requires matched physical-device measurements; no benchmark result is claimed without a connected device and trace.
