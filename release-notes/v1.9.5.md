# Audify 1.9.5 — Re-cut production release

This is the refreshed **1.9.5 (versionCode 47)** production release. The existing `v1.9.5` tag is being moved to the verified source commit for this re-cut, and the release includes phone, Android TV and Wear OS production APKs for all built ABIs.

## Final re-cut changes

- Standardized full-screen lyrics: ordinary scripts share a consistent left edge and fixed typography; Arabic-script lyrics retain right-to-left alignment. Removed active/inactive lyric size scaling.
- Fixed the Cloudflare integration test's relative source paths so the Android, web and Windows desktop protocol contract test resolves the actual platform files.
- Corrected Listen Together activity attribution so AutoPlay queue additions are not reported as manual member actions.
- Guarded Spotify playlist pagination against oversized final-page responses inflating the displayed track count beyond the playlist total reported by Spotify.
- Added missing `crossfade_on_skip` translations across supported locales and enabled Android translation validation for the base resource.
- Included the settings-migration recovery and migration-policy regression tests.

# Audify 1.9.5

## Search and visual polish

- Search's empty state is now deliberately quiet: mood and genre tiles, standard recent searches, and Addons recent searches are not shown before a query is entered.
- Search header, top-result cards, typeahead song rows and recent-result rows no longer paint opaque page-colour panels over the animated/background surface; the underlying backdrop remains visible.
- Restored full-width tablet layouts and corrected the bottom fade treatment to avoid a black slab around the bottom navigation.

## Playback, library and Wear OS reliability

- Local-library permission failures now explain the required access instead of appearing as an empty or successful partial library scan.
- Queue identity on Wear OS now uses entry IDs only when uniqueness is explicitly verified across the full phone queue; otherwise it falls back to stable queue positions.
- Wear queue publication is generation-ordered so an older asynchronous snapshot cannot replace a newer one.
- Clearing phone now-playing state clears stale playback and queue state on the watch.
- Reduced-motion settings now suppress in-flight skip movement and queue auto-follow animation; player and navigation touch targets are consistently sized.

## Scrolling and rendering performance

- Removed per-card spring, alpha and scale entrance animations from actively scrolling horizontal shelves.
- Retained bounded nested-shelf prefetching and native momentum scrolling.
- Progressive Blur defaults to **off** on fresh installs; an explicitly saved user choice remains unchanged during upgrades.

## Appearance and theme refinements

- Reworked light-theme surfaces around a clean neutral canvas, with clearer elevation steps, stronger separators and more legible secondary text.
- Reduced stacked accent tinting on light surfaces so cards, sheets and dialogs remain readable without flattening each theme pack's identity.
- Kept saved theme-pack IDs, custom palettes and dark-mode surface styles unchanged.

## Home stability and accessibility

- Home shelves now use stable identity keys instead of position-based keys, preventing feed updates from recreating shelf state when another shelf is inserted.
- The Recents loading placeholder and its loaded shelf retain the same identity; supplementary Recents loading starts after the primary Home feed is published.
- Suppressed shelf entrance reveals during active scrolling to avoid repeated visual flashes while the list is moving.
- Memoized Home's filtered shelf model and Library's pinned/sorted shelf model so unrelated playback and UI updates do not repeatedly allocate or sort the same feed data.
- Library grid cards now have stable, collision-safe item keys, including when provider data repeats a title or omits an ID.
- Home and Library layout controls expose named visibility and movement actions; move controls disable at pinned/unpinned boundaries.

## Onboarding and listening intent

- Onboarding progress and action copy now use the dedicated English resource file, and the progress indicator exposes an accessible step description.
- Radio sessions can be steered toward familiar artists, discovery, higher-energy or calmer tracks, or the provider's original order; explanations use available artist/energy signals and remain session-scoped.
- The radio explanation cache is bounded and refreshes recency when a track appears in a later batch.

## Smart Playlists and Library

- Added a dedicated **Create Smart Playlist** template card to the Library's Smart Playlists shelf. It opens the editor directly, without an extra navigation step.
- Reworked Smart Playlist creation and editing into a full-height Material 3 sheet, matching the app's existing playlist-sheet interaction, keyboard handling and dismissal behaviour.
- Smart Playlist cards now use the same Library card interactions as other playlists, including the long-press actions menu and pin/unpin support. Pinned Smart Playlists also appear in the Library's pinned grid.
- Smart Playlists remain stored locally and are excluded from YouTube Music upload by default.
- Moved **Sync Smart Playlists to YouTube Music** into **Privacy & Data**. It is off by default; its management dialog explains the upload scope, shows account sync status and errors, and supports a manual status refresh. Turning it off prevents queued Smart Playlist uploads from running. Existing remote copies are not deleted when sync is disabled.
- Updated the Library loading skeleton to show the two leading playlist action tiles in their real positions before the ordinary playlist covers, reducing layout mismatch when data arrives.

## Lyrics and Wear OS

- Lyrics now remain anchored to the left for ordinary scripts, regardless of inconsistent provider duet-alignment metadata; Arabic-script lines retain right-to-left presentation.
- Removed the enlarged blurred album-art layer behind full-screen lyrics, restoring the clean lyrics backdrop and preventing artwork text from bleeding into lyric lines.
- The Wear OS player now shows album metadata below artist information and correctly disables Previous when the phone reports that no previous track is available.
- Added manual refresh actions to the watch's Up Next queue and podcast subscription screens, including a disabled offline state for podcast refresh.
