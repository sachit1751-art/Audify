# Audify 1.9.4

## Restored settings and listening controls

- **Hide explicit content** now filters explicitly marked tracks from Home shelves, discovery and search results while leaving unmarked catalogue entries available.
- **Pause on mute** and **Resume on Bluetooth reconnection** are available again as playback preferences.
- **Time-aware discovery** brings a time-of-day listening shelf back to Home, with a setting to enable or disable it.
- Removed the **Your Week in Music** recap shelf from Home to keep the main feed focused.
- **Clear search history** is available in Settings.
- **YouTube Music sync status** can be refreshed from Settings for signed-in accounts.
- **Wear OS management** is reachable from Settings and reports paired watches, installation state and available updates.
- **Backup status** shows the latest automatic and external backup timestamps. Backup import now presents a confirmation step before restoring data.
- **Manual update checking** is available alongside the existing update notification and download flow.
- **Aurora, Ocean, Sunset and Nebula** built-in app backgrounds are available alongside Plain and custom photos. The selection is saved and follows the active colour theme; all 18 built-in colour themes remain available.
- **Liquid Glass** is off by default on fresh installs, with existing user preferences preserved.

## Feedback and updates

- Rebuilt **Report a bug** and **Suggest a feature** as full-screen, theme-aware forms with dedicated categories, clearer prompts and validation.
- Bug reports can include optional device and active audio-output diagnostics, a diagnostic preview and a text export. Android-restricted raw system logs are not collected.
- Screenshot selection is supported; the selected image must be attached on the GitHub issue page after the form opens it.
- Improved the update-screen presentation for download progress, release notes and update preferences.
- Fixed the About screen launcher-icon resource crash.

## Performance and Home

- Reduced continuous background animation work on Home service cards.
- Deferred Explore chart prefetch until Explore is opened, reducing startup network work.
- Paused Home artwork animation when Home is not the active screen, the app is backgrounded, or the player is open.
- These are targeted workload reductions; physical-device frame-time and memory validation is still required.

## Platform and reliability

- Updated shared catalogue filtering and Home presentation paths for the restored discovery controls.
- Retained the current player and appearance architecture while reconnecting the restored settings and Home entries.
- Updated the release version to **1.9.4 (43)** across the phone, TV and Wear OS build configuration.
