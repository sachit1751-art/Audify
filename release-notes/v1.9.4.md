# Audify 1.9.4

## Restored settings and listening controls

- **Hide explicit content** now filters explicitly marked tracks from Home shelves, discovery and search results while leaving unmarked catalogue entries available.
- **Pause on mute** and **Resume on Bluetooth reconnection** are available again as playback preferences.
- **Time-aware discovery** brings a time-of-day listening shelf back to Home, with a setting to enable or disable it.
- Removed the **Your Week in Music** recap shelf from Home to keep the main feed focused.
- **Clear search history** is available in Settings.
- **YouTube Music sync status** can be refreshed from Settings for signed-in accounts.
- **Wear OS management** is reachable from Settings and reports paired watches, installation state and available updates.
- **Backup status** shows the latest automatic and external backup timestamps. Backup import now presents a confirmation step before restoring data.
- **Manual update checking** is available alongside the existing update notification and download flow.
- **Aurora, Ocean, Sunset and Nebula** built-in app backgrounds are available alongside Plain and custom photos. The selection is saved and follows the active colour theme; all 18 built-in colour themes remain available.
- **Liquid Glass** is off by default on fresh installs, with existing user preferences preserved.
- Restored the classic sliding segmented selector as the shared default for app selectors, including search filters and dialogs; the crossfade duration slider remains a slider.
- Improved Settings search so multi-word queries can match across setting titles, descriptions and aliases, with punctuation and accent-insensitive matching.
- Pause on mute now tracks whether it paused the active player and resumes that same player when volume returns, without overriding a manual pause or a track change.
- Music-video cards use a landscape **16:9** thumbnail frame by default, matching the wider video presentation across Home shelves; the explicit square-thumbnail preference remains available.

## Automix audio analysis

- Bundled the Beat This! quantized ONNX model (`beat_this_final0_q8.onnx`) for beat/downbeat analysis and the quantized Open-Unmix vocal model (`vocals_umxhq_int8.onnx`) for vocal-activity analysis.
- Included ONNX Runtime Android native libraries in the production package so supported analysis can run locally on-device.
- Model inference, transition quality, device-specific memory use and performance still require physical-device testing; model presence in the APK is not a claim that every Automix transition has been validated.

## Motion and launcher appearance

- Restored the directional page-to-page transition between Home, Library and Explore, with the incoming page sliding in as the outgoing page moves away.
- Added a restrained fade alongside page pushes, page zooms, Bloom-style reveals, top-bar title changes and onboarding dismissal; reduced-motion preferences continue to disable page motion.
- Kept the transition treatment lightweight: no per-card blur or unnecessary staggered animation was added to the main navigation path.
- Added four adaptive launcher icon colourways: **Rose, Mint, Lavender and Ruby**, using the existing icon artwork and the same horizontal icon-selection layout.

## Feedback and updates

- Rebuilt **Report a bug** and **Suggest a feature** as full-screen, theme-aware forms with dedicated categories, clearer prompts and validation.
- Bug reports can include optional device and active audio-output diagnostics, a diagnostic preview and a text export. Android-restricted raw system logs are not collected.
- Screenshot selection is supported; the selected image must be attached on the GitHub issue page after the form opens it.
- Improved the update-screen presentation for download progress, release notes and update preferences.
- Fixed the About screen launcher-icon resource crash.

## Playlists and queue reliability

- Guest users can continue creating and editing local playlists without signing in. On the first validated Google sign-in, Audify snapshots the guest library into that account/profile's Room-backed sync outbox and schedules background sync; ordinary account switches do not copy one account's local library into another.
- Sync enqueue is retried on signed-in app restoration, so an interrupted first enqueue is recovered. Completed snapshots are idempotent; partial uploads resume in batches, and cloud conflicts are preserved for review.
- Fixed rapid playlist switching so an older queue start cannot replace a newer selection. Imported Spotify playlists now use playlist-bounded playback semantics, and stale bounded-playlist jobs are cleared when a new playlist starts.
- Playlist-wide shuffle now retains the selected starting track and shuffles the remaining playlist as one context.
- GitHub issue #37: fixed playlist switching so stale bounded-playlist continuation and older playback-start requests cannot replace the newly selected Spotify playlist.
- GitHub issue #38: added playlist-wide shuffle that keeps the selected track first and shuffles the remaining tracks across the full playlist (not just the current queue batch). Smart Shuffle recommendations remain a separate future enhancement.

## Library and player presentation

- Restored Quick Picks at the top of Library, reusing the Home feed mix shelf component and its existing card dimensions, artwork treatment and horizontal layout.
- Kept Playlists ahead of On Device, removed the duplicate On Device heading, and hide the On Device shelf entirely when the device has no saved albums or playlists.
- Moved Liked Music into the first position in the Playlists shelf and removed its separate Library shortcut/tile.
- Removed the Podcasts shelf from Library without deleting the standalone Podcasts feature.
- Adjusted the Home pull-to-refresh indicator inset so it clears the moving greeting/header.
- Player codec/bitrate/Automix status remains hidden by default; it can be enabled under Settings > Miscellaneous > Show player audio status.

## Performance and Home

- Reduced continuous background animation work on Home service cards.
- Deferred Explore chart prefetch until Explore is opened, reducing startup network work.
- Paused Home artwork animation when Home is not the active screen, the app is backgrounded, or the player is open.
- These are targeted workload reductions; physical-device frame-time and memory validation is still required.

## Platform and reliability

- Updated shared catalogue filtering and Home presentation paths for the restored discovery controls.
- Retained the current player and appearance architecture while reconnecting the restored settings and Home entries.
- Updated the release version to **1.9.4 (43)** across the phone, TV and Wear OS build configuration.

## Adaptive layouts

- Centered Home, Explore, Library and Search content on wide screens with a 1,000 dp maximum reading width; phone layouts continue to use the available width.
- Tightened the Home header's action targets and spacing below 360 dp so Search, Arrange Home and Profile remain usable on compact phones.
- Kept the existing adaptive Explore and Library grid column calculations and player/navigation width constraints.
- Restored the standard AndroidX edge-to-edge system-bar configuration rather than forcing custom navigation-bar styling that conflicts with Android 16's Taskbar-owned navigation window.
- Reworked Settings presentation to follow the supplied visual reference, with consistent section cards, icon alignment, spacing and adaptive content width across themes and screen sizes.
- Restored the original 1.9.2 selector style for the Theme and Font choices only; playback controls such as crossfade retain their existing slider design.
- Restored the 1.9.2 geometry for the standard bottom navigation while leaving the Liquid Glass navigation layout unchanged.
- Improved light-theme selected-state and accent contrast while retaining the original palette colours in theme previews.

## Discord Rich Presence

- Replaced the previous Discord presence transport with Discord's Android Social SDK integration.
- Added a dedicated Discord settings experience with a live presence-card preview, artwork and metadata visibility controls, elapsed-time display, audio-quality display, configurable action buttons, and playback privacy controls.
- Combined the selected track title, artist and optional album into one compact metadata line in the published presence.
- Added track start and expected end timestamps to presence updates so Discord has the timing data needed to render playback progress. The final progress-bar presentation is controlled by Discord and has not yet been verified in the Discord client.
- Deferred loading the native Discord SDK until Rich Presence is first used, and moved native library loading off the UI thread to avoid adding that work to cold startup.
- Updated the Home feed's primary-content ordering and aligned its loading skeleton with the displayed feed.
- Pull-to-refresh now reloads the supplemental Home browse shelves alongside the primary recommendations and Recents, then re-applies feed diversification and duplicate filtering.
- Home recommendations continue to use the live YouTube Music feed and continuation paging; horizontal shelves retain their native horizontal scrolling and do not force thumbnail dimensions.

## Appearance and wallpaper reliability

- Fixed the fluid wallpaper's initial-layout visibility check so an attached wallpaper is not incorrectly paused while the window reports a temporary zero-sized layout.
- Kept the wallpaper renderer lifecycle-aware and theme-aware; API fallback rendering remains available when the shader path is unsupported.
- Standardized remaining app segmented selectors on the classic sliding control while leaving the crossfade slider geometry and behavior unchanged.

## Lyrics provider priority

- `lrc.red` remains the first provider in the default lyrics lookup order. When it has no matching lyrics, the repository falls through to the next enabled provider in the listener's saved order.
- Existing user-defined provider order and disabled-provider choices are preserved.

- Prioritised Quick Picks in the initial Home feed so the shelf appears before the supplemental Home content; aligned the loading presentation with the shelf order.
- Unified Library and Settings page navigation around the shared directional transition.
- Improved text contrast in the Listen Together overlay for light surfaces.
- Refined the Liquid Glass preset tuning to reduce excessive refraction, saturation and shadow intensity.
- GitHub issue #40: manual Next/Previous commands now bypass the manual crossfade path and cancel an in-progress transition before moving the queue. Automatic crossfade at natural track endings remains available.
- Hardened playback recovery so audio-cache cleanup failures are logged without blocking retry and fallback resolution.
- Reorganised Android application sources under `core/app`, backend and native tooling under `core/`, and TV, Wear OS and web modules under `platforms/`; retained the Gradle wrapper at the repository root and updated CI, scripts, source references and documentation for the new paths.
- Rebuilt all 12 production APKs for phone, Wear OS and Android TV. Every APK passed `apksigner verify`, reports version **1.9.4 (43)**, and uses the same production signing certificate across phone, watch and TV. The six Cloudflare lifecycle tests pass.

## Home shelves and scrolling performance

- Restored Quick Picks as a horizontally scrollable shelf of three-track columns, with additional recommendations and a partial next-column preview.
- Updated the default Home music-video card ratio to landscape 16:9 instead of forcing portrait 9:16 thumbnails.
- Reduced Settings scroll-driven recomposition by deriving the scrollability boundary instead of reading the changing scroll offset directly in the scroll modifier.
