# Audify 1.9.3 — Release notes draft

> **Status: development build verification in progress.** This draft describes the changes prepared for 1.9.3. It is not a claim that a production release has been published or that every platform has completed device validation.

Audify 1.9.3 focuses on a cleaner Home experience, more reliable discovery, clearer settings, and dependable feedback reporting.

## What's changed

- **Cleaner Home header:** Removed duplicate Search and Account actions from the Home content header; the app-level actions remain available. Removed the Speed Dial shelf.
- **Podcasts on Home:** The Podcasts shelf loads independently from the main music feed, combining saved shows and provider discovery without waiting for the Home feed to finish. Podcast artwork and fallback icons use theme-aware foreground colours, including Light mode.
- **In-app feedback:** Added separate Report a bug and Suggest a feature flows. Submissions validate required fields, offer optional device diagnostics, and create GitHub issues through the secure feedback endpoint. The form does not ask users to sign in.
- **Shorter Settings rows:** Descriptions are limited to a single line, and self-explanatory controls no longer repeat their titles in a subtitle.
- **Crossfade control:** Restored the crossfade slider even when Automix is enabled; it remains available as a fallback length.
- **Themes and backgrounds:** Retains all 18 built-in colour themes, custom theme creation/import/export, and the app-wide custom background image setting. Theme colours are derived from the selected palette, with readable foreground contrast.
- **Home layout controls:** Reorder, hide and restore recommendation rows.
- **Elastic pull-to-refresh:** Home, Explore and Library follow the user's pull with visible refresh feedback.
- **Play Next by swiping:** Swipe a track row to place it immediately after the currently playing track, with the existing preference choosing Play Next or queueing.
- **Smoother lists and playback feedback:** Stable row identity reduces unnecessary list work; previous/next controls provide a short press animation that respects reduced-motion preferences.
- **Lyrics navigation:** Selecting another track from the lyrics panel returns to Now Playing.
- **Artwork preference:** Choose static cover art instead of looping video artwork where supported.
- **Theme Studio:** Create custom palettes with a live preview and direct colour controls.

## Platform availability and verification

Platform-specific controls must be validated on their intended devices. Phone/tablet, TV, Wear OS, Android Auto and Windows desktop do not share identical navigation or interaction models.

| Platform | Verification status |
| --- | --- |
| Android phone/tablet | Dev compile and APK build required for this draft; manual device review remains required |
| Android TV | TV build and D-pad verification required |
| Wear OS | Wear build and watch/emulator verification required |
| Android Auto | MediaLibrary host verification required |
| Windows desktop | Separate desktop build and interaction verification required |

## Feedback and privacy

Bug reports and feature suggestions are submitted anonymously to the Audify GitHub issue tracker. Device diagnostics are optional. Do not include passwords, account details, private listening history, or personal information; submitted text becomes a public issue.

- **Bug reports and feature suggestions:** Available in Settings → Miscellaneous.
- **Source code:** https://github.com/sachit1751-art/Audify
- **Releases:** https://github.com/sachit1751-art/Audify/releases
