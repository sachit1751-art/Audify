# Audify 1.8.2

**Release date:** 2026-10-31  
**Android phone / Wear OS version code:** 30  
**Android TV version code:** 28  
**Release tag:** `v1.8.2`

## Highlights

### Fixed
- Rebuilt the x86_64 FFmpeg JNI library with assembly disabled in the x86_64 build configuration. This addresses the emulator/runtime native-loader failure involving the missing `ff_psdsp_init_x86` symbol.
- Verified the rebuilt x86_64 app on the Android emulator; the previous native-loader warning did not recur during the observed launch and playback session.

### Player and lyrics
- Verified the existing landscape fullscreen lyrics experience on an Android x86_64 emulator.
- Confirmed portrait ? landscape ? portrait rotation preserves the lyrics presentation and artwork/actions layout.
- Confirmed media playback remains active and its playback position advances across both rotations; no Audify fatal exception was observed in the inspected log window.

### Documentation and project maintenance
- Reworked the README to remove promotional badges/claims, contributor graphics, maintainer/author credits, and donation/payment references; clarified features, build instructions, legal disclaimer, and release downloads.
- Updated Plan 027 with the current implementation paths and emulator verification results.
- Audited Plan 025 and confirmed the local-file library is already substantially implemented; no duplicate implementation or Room schema change was introduced.
- Removed five plan documents that were already deleted from the working tree; the deleted plans were not recreated.

## Downloads

- **Android phone:** universal APK works across supported ABIs; otherwise choose `arm64-v8a`, `armeabi-v7a`, or `x86_64`.
- **Android TV:** separate TV package, with universal and per-ABI APKs.
- **Wear OS:** companion watch APK.
- `SHA256SUMS.txt` contains SHA-256 checksums for every APK in this release.

All APKs are signed with the project's release signing certificate. The signing keystore and passwords are not included.

## Known verification limits

- Plan 027 translation toggling, no-lyrics fallback, and lyric scroll/history interactions were not separately exercised in this release pass.
- Local-file playback was not manually tested on a physical device during the Plan 025 audit.
- The build emits existing Android Gradle Plugin / compileSdk 37 compatibility warnings and R8 Kotlin metadata parsing warnings. These did not prevent the release builds from completing; they remain technical follow-up items.
