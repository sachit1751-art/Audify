# Audify 1.9.2

Audify 1.9.2 is a focused maintenance release with Android layout corrections and a more consistent Listen Together code-entry experience.

## What's changed

- **Scrollable screens:** Corrected content-inset and scrolling modifier order across Account & Scrobbling, Discord, Equalizer, Listen Together, Settings, Sources, and Wear OS settings so screen content scrolls within the available area without the inset moving with it.
- **Android release alignment:** Phone, Android TV, and Wear OS packages share version **1.9.2** and version code **41**.

## Downloads

- **Phone / tablet (universal):** `Audify-1.9.2.apk`.
- **Phone / tablet (ARM64):** `Audify-1.9.2_arm64-v8a.apk`.
- **Android TV / Google TV (universal):** `AudifyTV-1.9.2.apk`.
- **Wear OS (universal):** `AudifyWear-1.9.2.apk`.
- `SHA256SUMS.txt` lists the SHA-256 checksums for the APK assets.
