# Audify launch content kit

Use these drafts only after checking the current stable release link and community rules. Always disclose that you are the developer. Do not imply endorsements, user counts, or capabilities that have not been verified.

## 1. Short project introduction

I've been building Audify, an open-source music player and discovery client for Android. It combines music discovery, playlists, local audio, synchronized lyrics, and detailed playback controls, with separate Android TV and Wear OS builds. It is an independent third-party client, so connected-service availability can vary. I'm looking for a small group of Android users to try the latest stable build and share honest feedback. Source, screenshots, release notes, and downloads: https://github.com/sachit1751-art/Audify
