# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting flow:

1. Open the repository's [Security Advisories page](https://github.com/sachit1751-art/Audify/security/advisories).
2. Select **Report a vulnerability** to open a private report with the maintainers.
3. Include the affected version, impact, reproduction steps, and any relevant proof of concept. Do not include real account credentials or other people's private data.

If the private reporting option becomes unavailable, use the maintainer contact details on the [GitHub profile](https://github.com/sachit1751-art) and ask for a private reporting channel. Do not publish exploit details while a report is being reviewed.

## Supported versions

Security fixes are made against the current development branch. Users should update to the latest published stable release when one is available. Draft releases and prereleases are not stable releases.

## Scope

Reports may cover the Android, Android TV, Wear OS, desktop, web, and backend components maintained in this repository. Third-party services and libraries should be reported to their respective maintainers when the issue is outside Audify's control.
